PFE Brain Switch

The existing 28 recordings were rebuilt from scratch: causal preprocessing, Riemannian and deep models, and an evaluation that cannot be fooled by drift. The result is a real-time switch that detects when a person moves from rest into an imagined command. It works on people it has never seen, and it is backed by a physiological effect that drift cannot produce.

The old PFE models reported 35–50% on three classes. That number came from leaky splits and pipeline bugs, and the audit found no evidence they decoded anything. The new pipeline decodes one thing reliably (rest vs active), proves it with controls, and runs live at ~11 ms per decision.

In both protocols push always comes before walk, so any push-vs-walk classifier on these recordings can be explained by "earlier vs later". No preprocessing can fix that after the fact. Rest vs task is different: rest blocks sit between task blocks, so a monotonic drift cannot imitate the label. The switch is also exactly what a real-time controller needs first: is the user issuing a command right now?

  • Entering a command raises posterior beta. The strongest channels are {{", ".join(f"{c} {m:+.2f} dB (p={p:.4f})" for c, m, p in sorted(beta_on["channels"], key=lambda s: s[2])[:4])}}.
  • Leaving it lowers the same rhythm: {{", ".join(f"{c} {m:+.2f} dB (p={p:.4f})" for c, m, p in sorted(beta_off["channels"], key=lambda s: s[2])[:4])}}. Wilcoxon test across recordings.
  • Drift moves power in one direction over time, so it would give the same sign at both kinds of change. Opposite signs at onsets and offsets point to a genuine state change.
  • The classic motor-imagery signature (a mu/beta decrease over C3/C4) does not appear. The effect is posterior and positive, which fits an internally directed attention or imagery state: the participant disengages from the screen. That is what the switch decodes. It is honest, but it is not motor imagery.

Model progression, on people never seen

  • Causal re-centering whitens each window by the person's own exponentially weighted mean covariance over the last ~60 s. It removes slow drift and between-person offsets while keeping changes that happen within seconds, and it runs online unchanged.
  • Parieto-occipital channels (CP/P/O) carry the signal. Restricting the tangent-space model to them lifted cross-subject AUC from about 0.55 to 0.65.
  • Fusion = log-power of all 30 channels in 5 bands + tangent space of 12 posterior channels in 4 bands, logistic regression (C = 0.01), 4 s windows every 0.5 s, 8 s causal smoothing.
  • Null-controlled: within recording {{f"{conf['within']['mean']:.3f}"}} vs null {{f"{conf['within']['null_mean']:.3f}"}} ± {{f"{conf['within']['null_std']:.3f}"}}; cross-session {{f"{conf['xsess']['mean']:.3f}"}} vs {{f"{conf['xsess']['null_mean']:.3f}"}} ± {{f"{conf['xsess']['null_std']:.3f}"}}; cross-subject {{f"{conf['loso']['mean']:.3f}"}} vs {{f"{conf['loso']['null_mean']:.3f}"}} ± {{f"{conf['loso']['null_std']:.3f}"}}. Each beat all 30 shifts.
  • Nested: for each held-out person the configuration was chosen among 6 candidates using only the other 9. Result {{nested_auc}} (subject-level {{nested_subj}}), so the selection was not overfitted.
  • Ensemble averages the fusion model and ShallowConvNet with equal weights fixed before testing. Their errors are uncorrelated, so the ensemble gains about 0.04 AUC over either one and is the only model above chance for all 10 people.

Performance varies a lot between people and between sessions of the same person (S05: 0.90 on one session, 0.46 on another). This is normal for BCIs. A short calibration per user (fine-tuning the last layer or the logistic regression on 1–2 minutes of labelled rest/task) is the next lever, and the pipeline supports it.

  • Exact parity: the streaming decoder reproduces the offline features to machine precision, so every score on this page is what the live system would do.
  • Decision logic: P(active) is smoothed (8 s EMA) and compared with its own running mean (120 s). The switch turns on 2% above it for 1 s and off 2% below it. No per-user threshold is needed.
  • Artifacts: each output carries an artifact flag (peak-to-peak > 150 µV outside Fp1/Fp2) so the device can ignore those decisions.

The pipeline

Loadall_data only, hash-deduplicated, protocol from EDF markers, lazy reading
Cleanrobust bad-channel detection + spherical interpolation, >150 µV windows flagged
Filtercausal Butterworth bank 4–8, 8–12, 12–16, 16–24, 24–30, 8–30, 1–40 Hz, decimate to 125 Hz
Window2 s or 4 s, hop 0.5 s, 1 s guard at block edges, OAS covariances
Aligncausal Riemannian re-centering (τ 60 s) / causal Euclidean alignment for deep nets
Modellog-power + PO tangent space → LR, ShallowConvNet, 50/50 ensemble
Decide8 s EMA, adaptive threshold with hysteresis, artifact flag

Every step from Filter onwards uses only past samples. The code is in eegbci/. eegbci/README.md lists each command, from building the cache to the nested benchmark.

Limits and next steps

  • Push vs walk is out of reach with these recordings. Recording new data was ruled out, so the realistic design is a one-command switch (idle / go). Or the switch can be combined with a non-EEG selector (dwell time, a cyclic menu where the switch confirms the highlighted item) to get several commands from one reliable signal.
  • The signal is posterior and attention-like. The switch may also respond to other kinds of mental disengagement (daydreaming, eyes defocusing). It should be validated with false-positive tests during free viewing before driving anything that moves.
  • Per-user calibration helps. Adding the first 3–5 minutes of a session (labelled) to the cross-subject training set raised the AUC on the rest of that session from {{f"{calib['obs']['loso']:.3f}"}} to {{f"{calib['obs']['loso+cal']:.3f}"}}. The shifted-protocol null for the calibrated model is {{f"{np.mean([d['loso+cal'] for d in calib['nulls']]):.3f}"}} ± {{f"{np.std([d['loso+cal'] for d in calib['nulls']]):.3f}"}}. A short warm-up is worth building into the app.
  • Ensemble null: the deep branch was trained under shifted protocols too. Its null AUC ({{null_mean}}) is far below the real {{ens_auc}}, so the network is not learning drift either.
